# เส้นทางบรรจุ

[GitHub Pages](https://rat12-web.github.io/exam-path-tracker/) · [ข้อมูลออนไลน์เดิม](https://exam-path-personal-2026-r.rat-creative1.chatgpt.site/tracker/)

Site เป็นฐานข้อมูลส่วนตัวหลักสำหรับลำดับ ประวัติ และเอกสาร GitHub เก็บโค้ดและประกาศสาธารณะเท่านั้น ทั้งสองหน้าใช้ JavaScript/CSS และข้อมูลประกาศจาก Pages ชุดเดียวกัน เมื่อ Pages เผยแพร่แล้ว เปิด Site ใหม่จะได้รุ่นเดียวกัน

Pages พยายามเชื่อม Site อัตโนมัติ ถ้าเบราว์เซอร์บล็อกการเข้าระบบใน iframe ให้กดเชื่อมข้อมูลเดิม เข้าสู่ระบบ Site และเปิดหน้าต่างเชื่อมค้างไว้ ระบบรวมข้อมูลทุก 45 วินาทีพร้อมตรวจ revision เพื่อป้องกันข้อมูลจากอีกเครื่องถูกเขียนทับ กรณีเบราว์เซอร์ไม่รองรับ popup/opener ให้ใช้หน้า Site โดยตรง ข้อมูลในเครื่องยังเก็บไว้และส่งออก JSON ได้ เอกสารออนไลน์สูงสุด 6 MB

## อัปเดตประกาศ

GitHub Actions ตรวจ 9 หน่วยงานทุก 6 ชั่วโมงและเผยแพร่ Pages หน้าเว็บตรวจผลใหม่ทุก 10 นาที ThaiJobJob ใช้เครือข่าย Site ที่จำกัดเฉพาะแหล่งทางการและ GitHub encrypted secret ไม่มี credential ในโค้ดสาธารณะหรือเบราว์เซอร์ สำหรับ portal ที่รวมหลายโครงการ ตรวจ URL โครงการที่พบจริงจากหน้า landing ของหน่วยงาน

ประกาศใหม่มีสถานะรอตรวจความเกี่ยวข้อง ไม่เปลี่ยนลำดับเรียกจากข้อความที่ยังไม่ยืนยัน เอกสารสแกนยังต้องอ่านตรวจตำแหน่ง ปีบัญชี และช่วงลำดับ จำนวนเรียกและจำนวนบรรจุจริงแยกกัน วันที่กำหนดบรรจุไม่ได้ยืนยันว่ามาบรรจุครบ หากอ่านต้นทางไม่ได้แสดงข้อผิดพลาดและเก็บข่าวเดิม

GitHub อาจรันงานช้าหรือพัก schedule เมื่อ repo สาธารณะไม่มีความเคลื่อนไหว 60 วัน ดูเวลาตรวจล่าสุดและหน้า Actions

## ข้อมูลส่วนตัว

เก็บลำดับและประวัติเดิม เพิ่มกรมที่ดินในสถานะรอสมัคร ย้ายสนาม สป.เกษตรฯ ที่ไม่ได้สอบเข้าประวัติถอนตัวโดยไม่ลบข้อมูล กลุ่มโอกาสต่ำอยู่ท้ายสุด เปอร์เซ็นต์แสดงเฉพาะลำดับเรียกหารลำดับของฉัน การคาดการณ์เป็นสมมติฐาน ไม่ใช่ความน่าจะเป็น ไม่รวมการยืมที่ยังไม่ยืนยัน

## แจ้งเตือน LINE OA เข้าแชตส่วนตัว

ใช้ LINE Messaging API ส่งเฉพาะผู้รับที่ตั้งค่า ไม่ใช้ broadcast และไม่ต้องแก้ webhook ของ OA เดิม

1. เพิ่ม LINE OA เป็นเพื่อนใน LINE ส่วนตัว
2. เปิด [LINE Developers Console](https://developers.line.biz/console/) เลือก Messaging API channel ของ OA
3. แท็บ Messaging API: คัดลอก Channel access token ที่ใช้ส่งข้อความ
4. แท็บ Basic settings: คัดลอก Your user ID ซึ่งขึ้นต้นด้วย U และตามด้วยอักขระฐานสิบหก 32 ตัว (ไม่ใช่ LINE ID หรือ OA Basic ID)
5. เพิ่ม [GitHub Actions secrets](https://github.com/rat12-web/exam-path-tracker/settings/secrets/actions) สองชื่อ: LINE_CHANNEL_ACCESS_TOKEN และ LINE_RECIPIENT_ID ใส่ค่าเฉพาะในช่อง Secret ไม่ส่งในแชตหรือ commit
6. เปิดหน้า Actions เลือก Publish tracker and check announcements แล้ว Run workflow ครั้งแรกที่มีค่าครบจะส่งข้อความยืนยันการเชื่อมหนึ่งครั้ง รอบถัดไปเลือก line_test ได้เมื่อต้องการทดสอบอีกครั้ง

ตรวจทุก 6 ชั่วโมงและส่งหลัง deploy สำเร็จ แจ้งข่าวทางการที่ตรงโครงการปัจจุบัน พร้อมป้ายรอตรวจตำแหน่ง/ปีบัญชี ไม่เดาลำดับจาก PDF และแจ้งเมื่อลำดับสาธารณะที่ตรวจบันทึกแล้วเปลี่ยน ยังไม่รวมการแก้ข้อมูลส่วนตัวในฐานข้อมูล Site

ระบบเก็บประวัติแยกด้วย Actions cache และใช้ X-Line-Retry-Key คงเดิมเมื่อ retry รายการเดียวกัน ไม่ส่งข่าวย้อนหลังเมื่อเริ่มต้นหรือ cache หาย ส่งไม่เกิน 8 รายการต่อรอบ ที่เหลือรอรอบถัดไป LINE คิดจำนวนข้อความตามโควตาของ OA; HTTP 200 หมายถึงรับคำขอแล้ว ไม่รับประกันว่าผู้รับเห็นข้อความหากบล็อก OA

หากขาด secrets ระบบจะระบุว่ายังไม่เชื่อมโดยไม่ส่งข้อความ หาก API ปฏิเสธหรือยังส่งไม่สำเร็จ งาน notify-line จะล้มเหลวและเก็บประวัติรายการที่ส่งสำเร็จไว้ ไม่มี token หรือ user ID ใน public assets/logs
