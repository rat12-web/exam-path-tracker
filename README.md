# เส้นทางบรรจุ · GitHub Pages

ติดตามบัญชีสอบ ลำดับเรียก อายุบัญชี และประกาศจากหน่วยงานทางการ

ข้อมูลส่วนตัวและเอกสารเก็บในเบราว์เซอร์ ไม่ส่งขึ้น GitHub ใช้ส่งออก/นำเข้า JSON เพื่อสำรองบัญชีหรือย้ายเครื่อง เอกสารแนบดาวน์โหลดแยกกัน รุ่นนี้ไม่ซิงก์ข้ามอุปกรณ์กับเว็บเดิม

## อัปเดตอัตโนมัติ

GitHub Actions ตรวจหน้าประกาศ 9 หน่วยงานทุก 6 ชั่วโมง และเผยแพร่ผลพร้อมเว็บไซต์ เมื่อเปิดเว็บจะอ่านผลใหม่ทุก 10 นาที หรือกดตรวจอัปเดตได้

ระบบตรวจประกาศใหม่และเปลี่ยนแปลง แต่ไม่ตีความ PDF/ภาพเป็นลำดับเรียกอัตโนมัติ ต้องตรวจตำแหน่ง ปีบัญชี และช่วงลำดับก่อนบันทึก หน้าที่อ่านไม่ได้จะแสดงสถานะผิดพลาดและเก็บข่าวเก่าไว้ ลำดับเริ่มต้นเป็นข้อมูลตามวันที่กำกับ ไม่ใช่ลำดับสดจากต้นทาง

GitHub อาจรันงานช้าและพัก scheduled workflows ในคลังสาธารณะที่ไม่มีความเคลื่อนไหว 60 วัน ดูเวลาตรวจล่าสุดและสถานะ Actions เสมอ

## การเผยแพร่และทดสอบ

Pages Source: GitHub Actions ใช้ `.github/workflows/pages.yml` เมื่อ push, workflow_dispatch และ schedule

- `node --test tests/*.test.cjs`
- `python -m unittest discover -s tests -p 'test_*.py'`
- `python scripts/refresh.py`
- เปิดเว็บเซิร์ฟเวอร์ที่ `public/`

## ข้อจำกัดของคาดการณ์

เปอร์เซ็นต์แสดงเฉพาะลำดับเรียก ÷ ลำดับของฉัน ช่วงคาดการณ์เป็นสถานการณ์สมมติ ไม่ใช่ความน่าจะเป็น และไม่รวมการยืมที่ยังไม่ยืนยัน บัญชีอายุไม่เกิน 2 ปีและอาจยกเลิกก่อนเมื่อมีบัญชีใหม่

สถานะตรวจครั้งแรกบน GitHub: อ่าน สป.อว. ได้ ส่วน ThaiJobJob 8 แหล่ง timeout แม้เครื่องผู้ใช้เปิดได้ จึงแสดงสถานะขัดข้องและเก็บรายการเดิมไว้ มีผลค้นสำรองเฉพาะเมื่อพบรายการตรงหน่วยงาน ยังไม่รับรองว่าจะอัปเดตครบทุกต้นทางหรือลำดับเรียกอัตโนมัติ
